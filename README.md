## 📌 The Vision
The democratic process should be accessible to everyone, from tech-savvy urban youth to rural citizens below the poverty line. **Chunav Saathi** bridges the gap between complex bureaucratic government portals and the common man. It is an interactive, multi-lingual web application powered by AI that acts as a personal guide to the Indian election process.

## ✨ High-Impact Features

* 🧠 **Grounded AI Assistant:** Powered by **Gemini 1.5 Flash**, the chat assistant is strictly grounded in official Election Commission of India (ECI) guidelines. It answers queries about Form 6, EPIC cards, and polling stations natively without hallucination.
* 🌍 **Smart Geolocation & i18n:** The app detects the user's state via IP routing and dynamically suggests switching the UI to their regional language (e.g., prompting Kannada in Karnataka), drastically lowering the barrier to entry.
* 📈 **Interactive Visual Timeline:** Breaks down the intimidating election cycle into 4 digestible phases: Registration, Pre-Election, Polling Day, and Counting.
* 🏛️ **ECI Action Hub:** A beautiful, native UI grid that abstracts messy government websites, giving users direct, one-click access to critical actions (Check Electoral Roll, Download Voter Helpline App, View Candidate Affidavits).
* 🌓 **Adaptive Accessibility:** Fully responsive design with system-aware Light/Dark modes and high-contrast typography designed for readability across all devices.

## 🛠️ Tech Stack
* **Frontend:** Next.js (App Router), React, Tailwind CSS
* **UI Components:** `shadcn/ui`, Lucide Icons
* **AI Engine:** Google `@google/generative-ai` SDK (Gemini 1.5 Flash)
* **Deployment:** Vercel
